# Sentient Feed Takeover (Test)

This is a simple Next.js prototype that lets a user:

1. Choose one of several stock background images.
2. Upload a photo.
3. The server converts the photo into a high-contrast black-and-white image (approximate "outline").
4. The processed image is composited on top of the chosen background.
5. The user can download the final image.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Deploy on Vercel

1. Push this folder to a GitHub repo.
2. In Vercel, click **New Project**, select the repo.
3. Accept defaults and deploy.
